# 实验报告：大模型基于内容的文献真实性判断能力评估

## 1. 实验目标

评估当代大语言模型（LLM）根据bibliographic metadata（题目、作者、年份、会议）判断一个文献是否真实的能力。该任验旨在探索LLM在学术诚实性检验中的潜力，特别是在检测ghost citations（幽灵引用）中的表现。

## 2. 实验方法

### 2.1 任务设定

为每个LLM呈现bibliographic entry，包含以下字段：
- **Cite Title**: 文献标题
- **Authors**: 作者列表
- **Year**: 发表年份
- **Venue**: 发表场所（会议或期刊）

模型的任务是以JSON格式输出判断结果：
- `result`: 布尔值（true=文献真实，false=文献不真实）
- `reason`: 短句说明理由（1-3句）

## 4. 发现与解读

### 4.1 关键发现

1. **整体性能不足**：所有模型在本任务中的表现都远低于实际应用需求
   - 平均准确度仅39%
   - 没有模型在两个维度上都表现出色

2. **权衡问题**：存在明显的"准确度-召回率"权衡
   - 提高虚假文献检测能力会降低真实文献识别能力（如ERNIE）
   - 提高真实文献识别能力会增加虚假文献漏检（如UI-TARS）

3. **模型差异显著**：不同来源的LLM表现相差很大
   - 最优模型与最差模型的准确度相差50%以上
   - 模型规模与时间并非唯一决定因素

4. **知识限制问题**：
   - 模型可能无法有效识别小众领域的文献
   - 最新发表的文献可能超出模型的知识截断时间
   - 参数化记忆与在线搜索的整合效果有限

### 4.2 可能的原因

1. **任务复杂性**：仅基于metadata判断文献真实性是困难的
   - 需要关联多个信息源
   - 需要对学术出版生态的深入理解

2. **模型局限**：
   - 参数化知识不完整（尤其是最新文献）
   - 在线搜索能力有限
   - 难以区分相似但不同的出版物

3. **虚假文献设计**：
   - 虚假文献可能包含真实的author-venue组合或真实的title+year组合
   - 模型容易被具有高度真实感的虚假metadata迷惑

## 5. 结论

### 5.1 主要结论

当前大语言模型**不适合作为独立的文献真实性判断工具**，基于仅metadata的判断能力严重不足，平均准确度仅39%。

### 5.2 建议

1. **不应依赖单一模型**：应多模型投票或结合其他检验方式
2. **需要多模式输入**：仅用metadata不足，应包括摘要、参考文献等
3. **混合方法更优**：应结合数据库查询、相似度计算等传统方法
4. **持续监测**：随着模型升级，需要定期重新评估

### 5.3 对GhostCite框架的启示

- ✓ 使用自动化方法（标题相似度）比单纯依赖LLM判断更可靠
- ✓ 多源验证（DBLP、Google Scholar等）优于单一知识源
- ✓ 人工验证环节仍然重要，LLM辅助不能完全替代
- ✓ threshold-based方法（θ=0.9）的可解释性和鲁棒性优于LLM判断
