\section*{Open Science}

To facilitate future research, we release the source code of \textsc{CiteVerifier}, our Python-based citation verification system, at \url{https://anonymous.4open.science/r/GhostCite-7DBF/}. We hope this framework can serve the community in the future. To provide technical baseline and tool implementation references, the artifact includes the end-to-end pipeline (parsing, DBLP pre-match, online validation, caching), scripts for building a local DBLP title database, configuration templates, and detailed README instructions for setup and reproducibility. External database queries (DBLP, Google Scholar) require user-provided API credentials.
